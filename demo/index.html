About

This project provides an open-source font glyph and OpenType ligature for the Kurdistan Region of Iraq flag emoji sequence (ISO 3166-2 IQ-KR, CLDR subdivision iqkr). The current flag design is a draft placeholder whose geometry and colours remain unverified pending official legislative documentation. Source code and font builds are published in the project's GitHub repository.
